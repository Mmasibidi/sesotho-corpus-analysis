# Sesotho Corpus Analysis

## Project Description

This repository contains the code, documentation, and reproducible computational workflow for corpus-based analysis of Sesotho.

## Research Context

This project forms part of doctoral research on dictionary development for low-resourced languages, with a particular focus on corpus-based approaches to Sesotho lexicography.

## Data

The project uses the Autshumato Monolingual Corpus (Sesotho), version 2.1, as one of the corpus resources for the analysis.

## Software

The analysis will be conducted using Python and relevant Python libraries.

## Reproducibility

All computational procedures will be documented and version-controlled using Git and GitHub.
